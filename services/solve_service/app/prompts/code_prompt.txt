あなたの課題は、与えられた問題を記号的に解く Python コードを出力することです。

## ルール
- 最初に SymPy をインポートし、手順ごとの説明を格納するリスト process を作成してください。
- すべての変数は SymPy の symbols を使って定義してください（例: x = sp.symbols('X')）。
- 各推論ステップごとに、記号的な操作を行い、その手順と結果を文字列にして process に追加してください。
- 問題や手順に含まれる数値定数は使わず、すべて記号的に計算してください。
- 計算には SymPy の関数（例: sp.solve, sp.expand, sp.factor など）を用いてください。
- SymPy の関数名は公式 API に従い、すべて小文字で書いてください。
- 答えを手動で書かず、必ず記号的に導出してください。
- 数値計算（.evalf() や浮動小数）は使わないでください。
- 最終結果は results という変数に代入してください。
- コードの最後で必ず process と results を定義してください。
- 出力はできるだけ短く簡潔にしてください。
- 必要最小限の構造のみを出力し、余分な説明は入れないでください。
- 検算は不要です。
